# AeroFlow GT3 Endurance

**Design source:** [`prompts/examples/gt3-endurance.json`](../../../prompts/examples/gt3-endurance.json)

**Generated prompt package:** [`prompts/generated/gt3-endurance.md`](../../../prompts/generated/gt3-endurance.md)

**Generator:** [`plugin/tools/generate-gt3-model.mjs`](../../../plugin/tools/generate-gt3-model.mjs)

**Assets:**

- [`aeroflow-gt3-endurance.glb`](aeroflow-gt3-endurance.glb) — preferred import
- [`aeroflow-gt3-endurance.gltf`](aeroflow-gt3-endurance.gltf) — embedded resources
- [`aeroflow-gt3-endurance.obj`](aeroflow-gt3-endurance.obj) — OBJ test path
- [`aeroflow-gt3-endurance.manifest.json`](aeroflow-gt3-endurance.manifest.json) — dimensions + SHA-256

**Preview:** see [`previews/`](previews/) for offline software screenshots. They
are approximate flat-shaded views of the OBJ and are not captures of AeroFlow
Lab.

**Design intent:** a brand-free GT3 endurance concept with a long hood, cabin set
rearward, wide track, front splitter, canards, vented hood, side skirts, rear
diffuser, swan-neck rear wing, roof scoop, matte graphite body, and a single cyan
accent stripe. No real manufacturer, team, sponsor, or production-car geometry is
included.

**Dimensions:** recorded in the manifest; the importer normalizes display scale,
so set the real length/width/height and Cd in AeroFlow for the aerodynamic
proxy.
