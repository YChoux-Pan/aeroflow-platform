# Preview images

These are **offline software previews** rendered from the actual OBJ geometry
with a flat-shaded painter's-algorithm renderer. They are useful for design
review and for showing the asset in the repository, but they are not captures of
AeroFlow Lab and do not use the plugin's PBR environment, bloom, or camera.

| File | View |
|---|---|
| `aeroflow-gt3-front34.jpg` | front three-quarter |
| `aeroflow-gt3-side.jpg` | side profile |
| `aeroflow-gt3-rear34.jpg` | rear three-quarter |

If the model geometry changes, regenerate these images with any renderer or
remove them; the model manifest remains the source of truth for the asset files.
