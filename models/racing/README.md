# Racing asset index

- **AeroFlow Formula 01** — original open-wheel concept.
- Generator: `plugin/tools/generate-racing-model.mjs`.
- Manifest: [`manifest.json`](manifest.json) (dimensions + SHA-256).
- Formats: GLB (preferred), embedded glTF, OBJ.
- License: MIT with this repository.

Use these files to test AeroFlow Lab's **Import vehicle mesh** path. The model is
normalized for display; set real dimensions and Cd in the lab for aerodynamic
telemetry.

The model is not a real racing car and contains no team branding or sponsor
livery.
