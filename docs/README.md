## Project boundaries

- The flow visualization is a **proxy**, not CFD.
- The repository is a **DSH plugin + design tooling monorepo**, not a hosted web
  service.
- Upstream skills are **read-only snapshots** with their own licenses.
- The original racing model is **brand-free test geometry**, not a production car.
