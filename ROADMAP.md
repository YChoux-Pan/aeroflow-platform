# Roadmap

AeroFlow is a long-term engineering project. Priorities are reviewed at the
start of each quarter; completed work moves to `CHANGELOG.md`.

## Now (v1.2.x)

- [x] GLB/glTF import in AeroFlow Lab.
- [x] Original racing model fixtures and import smoke tests.
- [x] Prompt engineering schema, templates, compiler, examples.
- [x] Five-group skills library with pinned licenses.
- [x] CI, release packaging, maintenance journal.
- [x] White-smoke streamline renderer with a neutral studio strip.
- [x] Hellcat-inspired widebody preset and model.
- [x] Reference-frame vectorization and visual-language notes.
- [ ] Visual verification pass in DSH Desktop/Web on light and dark themes.
- [ ] First-run in-app note for supported import formats.

## Next (v1.3)

- [ ] Prompt Lab panel inside AeroFlow Lab: choose a template, preview, copy.
- [ ] Drag-and-drop multi-file glTF (`.gltf` + `.bin` + textures) on desktop.
- [ ] OBJ material (`.mtl`) companion import.
- [ ] Optional DRACO/Meshopt decoders packaged locally (no CDN).
- [ ] Asset metadata capture: real length, width, height, Cd preset.
- [ ] More original racing models: Le Mans hypercar, rally, touring car.
- [ ] Light/dark contrast audit of all HUD surfaces.

## Later (v2)

- [ ] Save/compare multiple test articles and runs.
- [ ] Export a run report (JSON + Markdown) for design reviews.
- [ ] Higher-fidelity aerodynamic surrogate with clear validation limits.
- [ ] Blender/Three.js asset bridge.
- [ ] GitHub Pages gallery of generated concepts and models.
- [ ] Community prompt packs with a license checklist and review workflow.

## Explicit non-goals

- Calling the visual field "CFD" or implying engineering certification.
- Bundling copyrighted production-car geometry or team liveries.
- Redistributing upstream skill content whose license does not permit it.
- Running untrusted build scripts during plugin installation.
