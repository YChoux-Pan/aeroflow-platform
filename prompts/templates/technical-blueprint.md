# Technical blueprint template

Use for aero communication, design reviews, and AeroFlow-style technical
presentation. This is not a validated engineering drawing.

## Template

```text
Technical blueprint of an original {vehicleClass}, {era}, {designLanguage}.
Orthographic {view}, precise proportions, {wheelToBodyPercent}% wheel-to-body,
{wheelbasePercent}% wheelbase, {rideHeightMm} mm ride height.
Visible {aero}, exposed suspension and floor structure.
Dimension lines, callout arrows, airflow direction arrows,
labelled aero components, section cut at the centerline.
Monochrome {blueprintColor} technical background with {accent} annotations,
white line work, grid, no logos, no text other than technical labels.
Clean industrial-design presentation, no perspective distortion.
Negative: no marketing copy, no logos, no real car identity, no illegible labels.
```

## Notes

- Orthographic side or top views are more useful than a hero angle.
- Keep annotations sparse; ask for a separate clean line drawing if the model
  cannot render legible labels.
- A blueprint is a communication aid, not a substitute for CAD or CFD.
- The AeroFlow HUD uses a similar cyan-on-navy visual language; pair this prompt
  with the plugin's technical palette when producing presentation art.
